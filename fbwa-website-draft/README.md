# FBWA public website draft

A standalone, responsive product landing page for FBWA (Food Business Web App). This is separate from the existing operations app and is ready to use as a Vercel static site.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```sh
npx serve .
```

## Publish on Vercel

Import the GitHub repository into Vercel and set **Root Directory** to `fbwa-website-draft`. No build command or output directory is needed; Vercel can serve the static files directly. Add a custom domain in the Vercel project settings when one is available.

## Before launch

- Replace the placeholder `hello@fbwa.app` contact address with the product's chosen contact.
- Confirm the preferred product name and domain before public launch.
- The hero photograph is served from Unsplash and the page uses Google Fonts.
